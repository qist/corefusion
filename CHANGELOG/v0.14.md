## v0.14.6 — 2026-11-28

> 路由规则可排序、可开关；Google 连通性探测直连置顶；证书邮件提醒与面板告警同口径；sing-box 路由页多语言补全。

### 中文

- **路由规则支持排序**：Xray 的 `routing.rules` 与 sing-box 的 `route.rules` 都新增 `↑ / ↓` 按钮，与出站排序一致（分页时按全局顺序禁用首尾按钮）。Xray 调整后立即保存并热下发；sing-box 点「保存」后写入并按需重启核心。
- **路由规则支持启用/停用**：规则列表左侧新增开关；停用规则保留在列表里（刷新后仍可再次打开），但运行配置生成时剔除，面板内部 `enabled` 字段不下发核心；xray 热下发路径同样先做清洗。编辑停用规则不会自动重新启用。
- **Google 连通性探测直连置顶**：`gstatic.com` / `googleapis.com` 直连基线规则调整为默认第一条；存量节点一次性迁移只重排已有规则，不新增或恢复用户删除的规则。
- **邮件 IP 证书到期提醒对齐面板告警**：含 IP 的证书改按有效期 1/3 计算提醒窗口（约 2 天），不再用固定 3 天窗口与自动续期阈值重合导致天天发邮件；域名证书仍提前 7 天。面板「异常告警」与邮件共用同一算法。
- **sing-box 路由页多语言补全**：页面内写死的标题、按钮、提示改为 16 种语言；配置枚举值保留英文原文，避免核心拒载。
- **操作手册更新**：`docs/USER-GUIDE` 新增 6.7「路由规则排序与启用开关」，16 种语言同步。

### English

- **Routing rules can be reordered**: `↑ / ↓` buttons for both Xray `routing.rules` and sing-box `route.rules`, matching the Outbounds page (first/last disabled correctly with pagination). Xray saves and hot-applies immediately; sing-box writes on Save and restarts the core when needed.
- **Routing rules can be enabled/disabled**: a switch on each rule; disabled rules stay in the list (visible after refresh and re-enableable) but are excluded from runtime configs, and the panel-only `enabled` field never reaches the core. The Xray hot-apply path sanitizes the payload too. Editing a disabled rule keeps it disabled.
- **Google connectivity direct rule first**: the `gstatic.com` / `googleapis.com` direct baseline is now the first default rule; a one-time migration only reorders existing rules and never restores deleted ones.
- **Email IP certificate alerts match panel warnings**: certs with IP identifiers now use one third of the validity period (about 2 days) instead of a fixed 3-day window that overlapped auto-renewal and caused daily emails. Domain certs still warn 7 days ahead; the dashboard and email share the same calculation.
- **sing-box routing page fully localized**: hardcoded labels, buttons and hints are translated into 16 languages; configuration enum values stay in English so the core still accepts them.
- **Manual updated**: `docs/USER-GUIDE` section 6.7 documents rule ordering and on/off switches in all 16 languages.

### Русский

- **Правила маршрутизации можно переставлять**: кнопки `↑ / ↓` доступны для `routing.rules` Xray и `route.rules` sing-box, как на странице исходящих соединений (при постраничном отображении первый/последний корректно блокируются). Xray сохраняет и применяет сразу; sing-box записывает по кнопке «Сохранить» и при необходимости перезапускает ядро.
- **Правила маршрутизации можно включать/отключать**: переключатель слева от правила. Отключённое правило остаётся в списке (видно после обновления и может быть снова включено), но исключается из рабочей конфигурации; внутреннее поле `enabled` не попадает в ядро. Горячее применение Xray тоже очищает полезную нагрузку. Редактирование отключённого правила не включает его.
- **Правило direct для Google connectivity теперь первое**: базовое правило `gstatic.com` / `googleapis.com` стоит первым по умолчанию; разовая миграция только переставляет существующие правила и не восстанавливает удалённые.
- **Уведомления по почте для IP-сертификатов соответствуют предупреждениям панели**: для сертификатов с IP используется одна треть срока действия (около 2 дней) вместо фиксированных 3 дней, совпадавших с автообновлением и вызывавших ежедневные письма. Для доменных сертификатов по-прежнему 7 дней; расчёт общий для панели и почты.
- **Страница маршрутизации sing-box переведена**: жёстко заданные подписи, кнопки и подсказки переведены на 16 языков; значения перечислений остаются на английском, чтобы ядро не отклонило конфигурацию.
- **Обновлено руководство**: в `docs/USER-GUIDE` добавлен раздел 6.7 о порядке правил и переключателях на всех 16 языках.

### فارسی

- **مرتبسازی قوانین مسیریابی**: دکمههای `↑ / ↓` برای `routing.rules` در Xray و `route.rules` در sing-box همانند صفحه خروجیها موجود است (در حالت صفحهمندی، اولین/آخرین بهدرستی غیرفعال میشوند). Xray بلافاصله ذخیره و اعمال میکند؛ sing-box با «ذخیره» مینویسد و در صورت نیاز هسته را راهاندازی مجدد میکند.
- **فعال/غیرفعال کردن قوانین مسیریابی**: کلیدی در سمت چپ هر قانون. قانون غیرفعال در فهرست باقی میماند (پس از تازهسازی دیده شده و دوباره فعال میشود) اما از پیکربندی اجرا حذف میشود و فیلد داخلی `enabled` به هسته ارسال نمیشود. مسیر اعمال داغ Xray نیز بار را پاکسازی میکند. ویرایش قانون غیرفعال آن را فعال نمیکند.
- **قرار گرفتن قانون مستقیم اتصال Google در ابتدا**: قانون پایه `gstatic.com` / `googleapis.com` بهطور پیشفرض اول میشود؛ مهاجرت یکبارهای فقط قوانین موجود را مرتب میکند و قوانین حذفشده را بازنمیگرداند.
- **همسانی هشدار ایمیل گواهی IP با هشدار پانل**: گواهیهای دارای IP اکنون از یکسوم مدت اعتبار (حدود 2 روز) بهجای 3 روز ثابت استفاده میکنند که با تمدید خودکار همپوشانی داشت و موجب ایمیل روزانه میشد. گواهیهای دامنه همچنان 7 روز هشدار میدهند؛ محاسبه بین پانل و ایمیل مشترک است.
- **تکمیل چندزبانه صفحه مسیریابی sing-box**: عنوانها، دکمهها و راهنماهای ثابت به 16 زبان ترجمه شدند؛ مقادیر شمارشی پیکربندی انگلیسی میمانند تا هسته آنها را نپذیرد.
- **بهروزرسانی راهنما**: بخش 6.7 در `docs/USER-GUIDE` به 16 زبان اضافه شد.

## v0.14.5 — 2026-11-27

> 安全审计 v8 补充修复：订阅凭证重加密、链式代理权限、外部节点脱敏、共享配置套餐隔离。

### 中文

- **修复订阅 token 重加密导致长链接全部 404**：历史密钥迁移对 `subscriptions.token` 与轮换历史改回确定性 nonce（短链 code 仍为随机 nonce + HMAC 指纹）；`corefusion migrate` 现在也会先确保主密钥就绪，不再静默使用主机名派生弱密钥。
- **收紧链式代理接口权限**：`/chain/*` 读操作至少 Operator，创建/修改/删除链式代理与注册外部虚拟入口仅 Admin。此前只读账号即可改全局链路并触发下发。
- **外部节点读接口对只读角色脱敏**：viewer 不再看到上游订阅 URL（常内嵌 token）、粘贴的节点原文和 `proxy_json` 中的 uuid/密码；名称/地址/端口等展示字段保留。
- **共享配置按套餐隔离**：订阅渲染 `?config=` / `?platform=` 现在与短链生成同口径校验 `PlanIDs`，不能再取到其他套餐的规则/模板（节点仍按套餐过滤）。
- **短链列表改回只读**：`GET /subscriptions/:id/short-links` 的清理与 `?expand=1` 补齐只对 Operator 及以上生效；门户短链拿不到对外域名时返回空、回退长链接，不再下发 `https://127.0.0.1/...`；关闭「自动创建」后 `/me` 不再写库。

### English

- **Fixed token re-encryption breaking every long subscription URL**: legacy-key migration now rewrites `subscriptions.token` and rotation history with a deterministic nonce (short-link codes stay random-nonce + HMAC fingerprint); `corefusion migrate` now ensures the primary key first instead of silently using the hostname-derived fallback.
- **Tightened chain-proxy permissions**: `/chain/*` reads require Operator; creating/updating/deleting chain links and registering external virtual entries require Admin. A read-only account could previously rewrite global routing and trigger pushes.
- **External-node reads are masked for read-only roles**: viewers no longer receive upstream subscription URLs (often containing tokens), pasted node source, or `proxy_json` credentials; display fields such as name/address/port remain.
- **Shared configs are scoped by plan**: `?config=` / `?platform=` now validate `PlanIDs` the same way short-link generation does, so another plan's rules/templates can no longer be fetched (nodes are still filtered by plan).
- **Short-link listing is read-only again**: cleanup and `?expand=1` backfill in `GET /subscriptions/:id/short-links` only run for Operator and above; portal short links return empty and fall back to long links when no public domain is configured (no more `https://127.0.0.1/...`); `/me` no longer writes rows when auto-create is disabled.

### Русский

- **Исправлено перешифрование токенов, из-за которого все длинные ссылки подписки отдавали 404**: миграция старых ключей теперь переписывает `subscriptions.token` и историю ротации с детерминированным nonce (коды коротких ссылок остаются со случайным nonce + HMAC-отпечатком); `corefusion migrate` сначала гарантирует наличие основного ключа, а не использует молча слабый ключ из имени хоста.
- **Ужесточены права интерфейса цепочки**: чтение `/chain/*` требует Operator, создание/изменение/удаление цепочек и регистрация внешних виртуальных входов — только Admin. Раньше аккаунт только для чтения мог менять глобальную маршрутизацию и запускать рассылку конфигурации.
- **Чтение внешних узлов маскируется для ролей только для чтения**: viewer больше не получает URL вышестоящей подписки (часто с токеном), исходный текст узлов и учётные данные из `proxy_json`; имя/адрес/порт остаются.
- **Общие конфигурации ограничены тарифом**: `?config=` / `?platform=` теперь проверяют `PlanIDs` так же, как при создании коротких ссылок, поэтому правила/шаблоны другого тарифа недоступны (узлы по-прежнему фильтруются по тарифу).
- **Список коротких ссылок снова только для чтения**: очистка и `?expand=1` в `GET /subscriptions/:id/short-links` выполняются только для Operator и выше; портал возвращает пустую ссылку и откатывается на длинную, если внешний домен не настроен (больше нет `https://127.0.0.1/...`); при выключенном автосоздании `/me` не пишет в БД.

### فارسی

- **رفع مشکل رمزنگاری مجدد توکن اشتراک که همه لینک‌های بلند را 404 می‌کرد**: مهاجرت کلید قدیمی اکنون `subscriptions.token` و تاریخچه چرخش را با nonce قطعی بازنویسی می‌کند (کد لینک کوتاه همچنان nonce تصادفی + اثرانگشت HMAC دارد)؛ `corefusion migrate` ابتدا کلید اصلی را تضمین می‌کند و دیگر بی‌صدا از کلید ضعیف مشتق از نام میزبان استفاده نمی‌کند.
- **سخت‌تر شدن مجوزهای زنجیره پروکسی**: خواندن `/chain/*` حداقل Operator؛ ایجاد/ویرایش/حذف زنجیره و ثبت ورودی مجازی خارجی فقط Admin. قبلاً حساب فقط‌خواندنی می‌توانست مسیریابی جهانی را تغییر دهد و ارسال تنظیمات را فعال کند.
- **پوشاندن خواندن گره‌های خارجی برای نقش‌های فقط‌خواندنی**: viewer دیگر URL اشتراک بالادستی (که اغلب توکن دارد)، متن منبع گره و اعتبارنامه `proxy_json` را نمی‌بیند؛ نام/آدرس/پورت باقی می‌ماند.
- **محدود شدن پیکربندی مشترک به پلن**: `?config=` / `?platform=` اکنون `PlanIDs` را مانند ساخت لینک کوتاه بررسی می‌کند، بنابراین قواعد/قالب پلن دیگر قابل دریافت نیست (گره‌ها همچنان بر اساس پلن فیلتر می‌شوند).
- **فهرست لینک کوتاه دوباره فقط‌خواندنی شد**: پاک‌سازی و `?expand=1` در `GET /subscriptions/:id/short-links` فقط برای Operator و بالاتر اجرا می‌شود؛ پورتال در نبود دامنه عمومی رشته خالی برمی‌گرداند و به لینک بلند برمی‌گردد (دیگر `https://127.0.0.1/...` نیست)؛ با خاموش بودن ساخت خودکار، `/me` دیگر ردیف نمی‌سازد.

## v0.14.4 — 2026-11-27

> 修复无配置的 Mihomo 短链；订阅 token / 短链 code / 上游订阅 URL 加密落库（短链 code 改为 HMAC 指纹查询 + 撤销表）。

### 中文

- **无配置的 Mihomo 短链不再生成**：`mihomo_yaml` 现在和 sing-box / Xray 一样必须绑定配置。打开「短链」弹窗会自动清理该订阅下无配置的存量 mihomo 链接；手动创建 / 更新无配置的 mihomo 链接会被拒绝。
- **订阅凭证加密落库**：`subscriptions.token` 与轮换历史 token 使用 AES-256-GCM 加密；短链 code 改为「随机 AES-256-GCM 密文 + HMAC-SHA256 指纹查询」，新增撤销记录表，轮换 / 删除后旧短码不可再解析；外部订阅源 `source_url` 也改为随机 AES-256-GCM。
- **升级提示**：升级前备份数据库，并保留 `CF_SECRET_ENCRYPTION_KEY`；不要回滚到旧版本——旧版本读不了加密后的 token / 短码，订阅会全部 404。

### English

- **No more unconfigured Mihomo short links**: `mihomo_yaml` now requires a config, same as sing-box / Xray. Opening the short-link dialog purges existing unconfigured Mihomo links; manual create/update without a config is rejected.
- **Subscription credentials encrypted at rest**: `subscriptions.token` and rotation-history tokens use AES-256-GCM; short-link codes now use a random AES-256-GCM ciphertext plus an HMAC-SHA256 fingerprint for lookup, with a revocation table so rotated/deleted codes can no longer resolve; the external subscription source `source_url` is encrypted too.
- **Upgrade note**: back up the database and keep `CF_SECRET_ENCRYPTION_KEY`; do not roll back to an older binary — it cannot read the encrypted tokens/codes, and all subscriptions will 404.

### Русский

- **Больше нет коротких ссылок Mihomo без конфигурации**: `mihomo_yaml`, как и sing-box / Xray, требует конфигурацию. При открытии диалога коротких ссылок старые ссылки без конфигурации удаляются; создание/обновление без конфигурации отклоняется.
- **Учётные данные подписок шифруются в БД**: `subscriptions.token` и токены истории ротации — AES-256-GCM; код короткой ссылки — случайный AES-256-GCM + HMAC-SHA256 для поиска, добавлена таблица отзыва, старые коды после ротации/удаления больше не работают; `source_url` внешнего источника подписки также шифруется.
- **При обновлении**: сделайте резервную копию БД и сохраните `CF_SECRET_ENCRYPTION_KEY`; не откатывайтесь на старую версию — она не сможет прочитать зашифрованные токены/коды, все подписки вернут 404.

### فارسی

- **دیگر لینک کوتاه Mihomo بدون پیکربندی ساخته نمی‌شود**: `mihomo_yaml` مانند sing-box / Xray به پیکربندی نیاز دارد. با باز کردن پنجره لینک‌های کوتاه، لینک‌های قدیمی بدون پیکربندی پاک می‌شوند و ایجاد/ویرایش بدون پیکربندی رد می‌شود.
- **رمزنگاری اعتبارنامه‌های اشتراک در دیتابیس**: `subscriptions.token` و توکن‌های تاریخچه چرخش با AES-256-GCM رمزنگاری می‌شوند؛ کد لینک کوتاه با AES-256-GCM تصادفی + اثرانگشت HMAC-SHA256 جستجو می‌شود، جدول لغو اضافه شده و کدهای قدیمی پس از چرخش/حذف کار نمی‌کنند؛ `source_url` منبع اشتراک خارجی نیز رمزنگاری می‌شود.
- **هنگام ارتقا**: از دیتابیس پشتیبان بگیرید و `CF_SECRET_ENCRYPTION_KEY` را نگه دارید؛ به نسخه قدیمی بازنگردید — نسخه قدیمی توکن/کد رمزنگاری‌شده را نمی‌خواند و همه اشتراک‌ها 404 می‌شوند.

## v0.14.3 — 2026-11-27

> 修复 YAML 生成把 `find-process-mode: off` 写成布尔 false；修复编辑订阅格式时切换第二份仍显示第一份内容。

### 中文

- **YAML 标量加引号**：生成 mihomo 配置时，`off` / `on` / `yes` / `no` / `y` / `n` / `null` / `~` 等 YAML 1.1 布尔/空值字面量统一加引号；此前 `find-process-mode: off` 会被客户端解析成 `false`，mihomo 直接报 `invalid find process mode`。
- **编辑订阅格式串数据**：`MihomoConfig` 组件把 `rule-providers` 拷贝到本地列表后没有监听 props，弹窗复用时会一直显示上一次打开的配置，需要刷新页面才恢复。现在监听 props 变化并重建列表，同时格式编辑弹窗加 `destroy-on-close`，切换第二份配置立即渲染新内容。

### English

- **Quote YAML scalars**: `off` / `on` / `yes` / `no` / `y` / `n` / `null` / `~` are now quoted when generating mihomo YAML. Previously `find-process-mode: off` was parsed as `false` and mihomo failed with `invalid find process mode`.
- **Format editor showed previous config**: the `MihomoConfig` component copied `rule-providers` into local state without watching props, so reusing the dialog kept showing the previously opened config until a page reload. It now watches props and rebuilds the list, and the format dialog uses `destroy-on-close` so switching to a second config renders immediately.

### Русский

- **Кавычки для YAML-скаляров**: при генерации mihomo YAML значения `off` / `on` / `yes` / `no` / `y` / `n` / `null` / `~` теперь берутся в кавычки. Раньше `find-process-mode: off` превращался в `false`, и mihomo падал с `invalid find process mode`.
- **Редактор формата показывал предыдущую конфигурацию**: компонент `MihomoConfig` копировал `rule-providers` в локальное состояние без наблюдения за props, поэтому при повторном открытии диалога отображалась старая конфигурация до перезагрузки страницы. Теперь props отслеживаются, список перестраивается, а диалог использует `destroy-on-close`.

### فارسی

- **بررسی امنیتی گره (جدید)**: در جزئیات گره → «بررسی» — جمع‌آوری فقط‌خواندنی سیستم، SSH، فایروال و پارامترهای هسته با درجه‌بندی high / warn / info / ok، کش ۱۰ دقیقه‌ای، بازخوانی دستی و گزارش کامل Markdown (کپی / دانلود / مشاهده آنلاین).
- **دستورهای پیشنهادی ماندگار می‌شوند**: پارامترهای هسته در `/etc/sysctl.d/99-corefusion.conf` (حذف تکراری‌ها و سپس `sysctl --system`)، SSH در `/etc/ssh/sshd_config.d/00-corefusion-*.conf` و ماژول BBR در `/etc/modules-load.d/`؛ پس از ری‌استارت باقی می‌مانند.
- **بررسی اولویت تنظیمات (CFG-01/02)**: برای هر کلید sysctl آخرین تعریف مؤثر (`/etc/sysctl.conf` همیشه آخر) و برای sshd نخستین دستور منطبق (اولین تطابق برنده است؛ drop-in به پیشوند `00-` و قرار گرفتن `Include` پیش از این دستورها نیاز دارد) نمایش داده می‌شود.
- **بررسی‌های IPv6 (IPV6-01~06)**: تنها وقتی گره IPv6 عمومی دارد — forwarding، ریدایرکت ICMPv6، source routing، افزونه‌های حریم خصوصی، جدول همسایه‌ها و سقف کش مسیر. نشانی تونل‌ها (`singbr0` / `wg0` / `tun0`) با برچسب `tun` جدا می‌شود، عمومی محسوب نمی‌شود و دستی ویرایش نمی‌شود.
- **معنای ورود root**: وقتی احراز هویت با گذرواژه و keyboard-interactive خاموش است، `PermitRootLogin yes` تأیید می‌شود (فقط با کلید) و دیگر پیشنهاد خاموش‌کردن root داده نمی‌شود.
- **گره اجرا و کارت شبکه خروجی**: هستهٔ موقت می‌تواند روی هر Agent اجرا شود و فهرست کارت‌های شبکه از همان گره گرفته می‌شود؛ xray / sing-box / mihomo از اتصال به کارت شبکه خروجی پشتیبانی می‌کنند (خالی = مسیر پیش‌فرض).
- **انتخاب هسته بر اساس گره اجرا**: فقط هسته‌های واقعاً نصب‌شده روی همان گره با نسخه فهرست می‌شوند؛ نصب/نصب مجدد روی گرهٔ دور از طریق Agent (بدون SSH) انجام می‌شود و نبود هسته خطای روشن با فهرست هسته‌های موجود می‌دهد.
- **بررسی پروکسی زنجیره‌ای**: تغییر نام یافته؛ بازه و هسته قابل ارث‌بری یا تنظیم مستقل است و در زمان‌بندی با بررسی IPهای منتخب ناسازگار است (بررسی دستی همچنان کار می‌کند).
- **بررسی اتصال به‌تفکیک فهرست**: صفحهٔ استخر CF IP فقط IPها و صفحهٔ دامنه‌های اشتراکی فقط دامنه‌ها را به‌روز می‌کند.
- **مستندات**: `docs/node-tuning.*.md` در ۱۶ زبان و فصل جدید در `USER-GUIDE`.

> یادآوری به‌روزرسانی: فرمان بررسی زنجیره‌ای به پروتکل Agent اضافه شده است، بنابراین **پنل و Agent باید با هم به‌روزرسانی شوند**.
