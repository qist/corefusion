## v0.13.0-rc.3 — 2026-11-21

> 发布候选（RC）：修复「实时日志」列出未启动进程的问题。

### 中文

- **实时日志**：来源列表改为与「发现日志」同口径，只返回已安装且正在运行的 nginx / caddy / WAF / xray / sing-box；未启动的核心或代理不再显示必然为空的日志路径。远程节点在 Agent 升级后同样生效。

### English

- **Realtime logs**: the realtime log source list now uses the same availability filter as log discovery and only returns installed, running nginx / caddy / WAF / xray / sing-box. Stopped cores or proxies no longer expose log paths that can only be empty. Remote nodes get the same behavior after their Agent is updated.

### Русский

- **Логи в реальном времени**: список источников теперь использует тот же фильтр доступности, что и обнаружение логов, и показывает только установленные и запущенные nginx / caddy / WAF / xray / sing-box. Остановленные ядра и прокси больше не предлагают заведомо пустые пути к логам. На удалённых узлах поведение появится после обновления Agent.

### فارسی

- **گزارش‌های زنده**: فهرست منابع گزارش اکنون از همان فیلتر دسترس‌پذیری «کشف گزارش» استفاده می‌کند و فقط nginx / caddy / WAF / xray / sing-box نصب‌شده و در حال اجرا را برمی‌گرداند. هسته‌ها یا پروکسی‌های متوقف دیگر مسیرهای خالی را نمایش نمی‌دهند. در گره‌های راه دور پس از به‌روزرسانی Agent اعمال می‌شود.

## v0.13.0-rc.2 — 2026-11-21

> 发布候选（RC）：修复 sing-box 实时连接状态与在线账号归户问题。

### 中文

- **sing-box 实时连接**：修正 clash_api 监听地址读取的字段（应为 `experimental.clash_api.external_controller`，兼容历史 `listen`），修复节点已开启 clash_api 仍被判为「未开启」的问题；未开启时明确展示「已关闭」，不再把 `connection refused` 误报成故障。
- **在线账号归户**：修复从邮箱提取订阅 ID 时把数字前缀当成 ID（如 `4wei@163.com` → `4`），避免直连账号被错误归到其他订阅/套餐。

### English

- **sing-box live connections**: fixed reading the clash_api listen address from the wrong field (should be `experimental.clash_api.external_controller`, with a legacy `listen` fallback), so nodes with clash_api enabled are no longer reported as disabled; when disabled, the UI now shows "disabled" instead of surfacing `connection refused` as a failure.
- **Online attribution**: fixed subscription ID extraction treating a numeric email prefix as the ID (e.g. `4wei@163.com` → `4`), which could attribute direct accounts to another subscription/plan.

### Русский

- **Живые подключения sing-box**: исправлено чтение адреса clash_api из неправильного поля (нужно `experimental.clash_api.external_controller`, с поддержкой старого `listen`), поэтому узлы с включённым clash_api больше не считаются отключёнными; при отключении интерфейс показывает «отключено», а не ошибку `connection refused`.
- **Привязка онлайн-аккаунтов**: исправлено извлечение ID подписки, когда числовой префикс почты принимался за ID (например, `4wei@163.com` → `4`) и прямой аккаунт мог попасть в чужую подписку/тариф.

### فارسی

- **اتصال‌های زنده sing-box**: خواندن آدرس clash_api از فیلد اشتباه اصلاح شد (باید `experimental.clash_api.external_controller` باشد، با پشتیبانی از `listen` قدیمی)؛ گره‌هایی که clash_api فعال دارند دیگر «غیرفعال» گزارش نمی‌شوند و در حالت غیرفعال به‌جای خطای `connection refused` وضعیت «بسته» نمایش داده می‌شود.
- **انتساب حساب‌های آنلاین**: استخراج شناسه اشتراک اصلاح شد؛ پیش‌تر پیشوند عددی ایمیل به‌اشتباه شناسه تلقی می‌شد (مثلاً `4wei@163.com` → `4`) و حساب مستقیم به اشتراک/طرح دیگری نسبت داده می‌شد.

## v0.13.0-rc.1 — 2026-11-20

> 发布候选（RC）：功能已冻结，正式版前只接受缺陷修复。

### 中文

- **支付站点**：充值订单支持按类型筛选（充值 / 套餐·流量包购买，含 CSV 导出）；站点启停改用独立端点，修复整行回传把掩码密钥当真值写回、缺字段清空 API Key/渠道的问题；403 提示带出后端原因。
- **门户充值**：打开「去充值」即加载支付站点并默认选中在线支付（原来只有买套餐才加载，直接充值只剩卡密）；存量门户模板自动打幂等补丁。
- **WAF**：补齐 25 个管理端接口白名单（支付站点、客户、套餐、卡券、工单等），修复保存支付站点时被 SSRF 规则（`http://127.0.0.1`）误拦成 403；防护未整体关闭。
- **WAF 同步调度**：上次同步时间落库，重启后按「上次同步 + 间隔」续算；`0 3 * * *` 等按本地时区墙上时间执行（不再等价于「启动后 24 小时」）；错过窗口时启动后补跑。修复面板频繁重启导致 24 小时同步永远不执行。
- **Agent 更新签名**：新增 `HeartbeatService.GetRuntimeConfig`，老节点自更新到本版本后自动把面板公钥写入 `config.yaml` 的 `update.public_key`（已配置不覆盖、写入 0600），恢复更新包 ed25519 强制验签。
- **测试工具**：新增本地模拟支付站点（收银台、回调观测、错签名/金额篡改/重放/失败回调），用于联调。

### English

- **Payment sites**: charge orders can be filtered by type (top-up vs plan/traffic-pack purchase, CSV export included); site enable/disable now uses a dedicated endpoint, fixing masked secrets being written back as real values and missing fields wiping the API key/methods; 403 responses now include the backend reason.
- **Portal top-up**: opening the recharge dialog loads payment sites and selects online payment by default (previously only plan purchases did); existing portal templates get an idempotent patch.
- **WAF**: added 25 admin API prefixes to the whitelist (payment sites, clients, plans, cards, tickets, ...), fixing saves of payment sites being blocked by the SSRF rule (`http://127.0.0.1`) with a 403; protection is still enabled overall.
- **WAF sync scheduler**: the last sync time is persisted so restarts resume from "last sync + interval"; daily expressions such as `0 3 * * *` now run at local wall-clock time instead of "24 hours after start"; overdue schedules catch up shortly after startup. Fixes 24-hour syncs never running on panels that restart often.
- **Agent update signature**: new `HeartbeatService.GetRuntimeConfig` lets upgraded legacy nodes write the panel public key into `config.yaml` (`update.public_key`; never overwritten when present, written with 0600), restoring mandatory ed25519 verification for self-updates.
- **Test tooling**: added a local mock payment gateway (cashier, callback inspection, bad signature/amount tampering/replay/failed callback) for integration testing.

### Русский

- **Платёжные сайты**: заказы пополнения фильтруются по типу (пополнение / покупка тарифа или пакета трафика, включая экспорт CSV); включение/выключение сайта переведено на отдельный эндпоинт — маскированный секрет больше не записывается как реальный, а отсутствующие поля не стирают API-ключ и способы оплаты; в ответах 403 теперь есть причина от бэкенда.
- **Пополнение в портале**: при открытии окна пополнения загружаются платёжные сайты и по умолчанию выбирается онлайн-оплата (раньше это работало только при покупке тарифа); для существующих шаблонов портала применяется идемпотентный патч.
- **WAF**: в белый список добавлены 25 префиксов админ-API (платёжные сайты, клиенты, тарифы, карты, тикеты и т.д.); сохранение платёжного сайта больше не блокируется правилом SSRF (`http://127.0.0.1`) с ответом 403; защита в целом остаётся включённой.
- **Планировщик синхронизации WAF**: время последней синхронизации сохраняется в БД, после перезапуска отсчёт идёт от «последняя синхронизация + интервал»; выражения вида `0 3 * * *` выполняются по локальному времени, а не «через 24 часа после старта»; пропущенные окна догоняются вскоре после запуска. Исправлена ситуация, когда при частых перезапусках синхронизация раз в 24 часа не выполнялась никогда.
- **Подпись обновлений Agent**: новый `HeartbeatService.GetRuntimeConfig` позволяет обновлённым старым узлам записать публичный ключ панели в `config.yaml` (`update.public_key`; существующее значение не перезаписывается, права 0600), возвращая обязательную проверку подписи ed25519.
- **Тестовые инструменты**: добавлен локальный макет платёжного шлюза (касса, просмотр колбэков, неверная подпись/подмена суммы/повтор/failed callback) для интеграционного тестирования.

### فارسی

- **سایت‌های پرداخت**: سفارش‌های شارژ بر اساس نوع قابل فیلتر شدند (شارژ / خرید طرح یا بسته ترافیک، همراه با خروجی CSV)؛ فعال/غیرفعال کردن سایت به یک نقطه پایانی جدا منتقل شد تا کلید ماسک‌شده به‌عنوان مقدار واقعی ذخیره نشود و فیلدهای خالی کلید API و روش‌های پرداخت را پاک نکنند؛ پاسخ 403 دلیل بک‌اند را نشان می‌دهد.
- **شارژ در پورتال**: با باز کردن پنجره شارژ، سایت‌های پرداخت بارگذاری و پرداخت آنلاین به‌صورت پیش‌فرض انتخاب می‌شود (پیش‌تر فقط هنگام خرید طرح بارگذاری می‌شد)؛ قالب‌های موجود پورتال وصله تکرارپذیر می‌گیرند.
- **WAF**: ۲۵ پیشوند از API مدیریت (سایت‌های پرداخت، مشتریان، طرح‌ها، کارت‌ها، تیکت‌ها و...) به فهرست سفید اضافه شد؛ ذخیره سایت پرداخت دیگر توسط قاعده SSRF (`http://127.0.0.1`) با خطای 403 مسدود نمی‌شود؛ حفاظت کلی همچنان فعال است.
- **زمان‌بند همگام‌سازی WAF**: زمان آخرین همگام‌سازی در پایگاه داده ذخیره می‌شود و پس از راه‌اندازی مجدد از «آخرین همگام‌سازی + فاصله» ادامه می‌یابد؛ عبارت‌هایی مانند `0 3 * * *` بر اساس زمان محلی اجرا می‌شوند، نه «۲۴ ساعت پس از شروع»؛ پنجره‌های ازدست‌رفته کمی پس از راه‌اندازی جبران می‌شوند. مشکل اجرا نشدن همگام‌سازی ۲۴ ساعته در پنل‌هایی که زیاد ری‌استارت می‌شوند برطرف شد.
- **امضای به‌روزرسانی Agent**: `HeartbeatService.GetRuntimeConfig` جدید باعث می‌شود نودهای قدیمی پس از به‌روزرسانی، کلید عمومی پنل را در `config.yaml` (`update.public_key`؛ در صورت وجود بازنویسی نمی‌شود، با دسترسی 0600) بنویسند و بررسی اجباری امضای ed25519 بازگردد.
- **ابزار تست**: یک درگاه پرداخت ساختگی محلی اضافه شد (صفحه پرداخت، مشاهده callback، امضای نامعتبر/دستکاری مبلغ/تکرار/پرداخت ناموفق) برای تست یکپارچه.

## v0.13.0-beta.100 — 2026-11-20

### 中文

- **安全审计 v7 收尾**：安装令牌改走请求头、Agent 引导不再默认 TOFU、更新包 ed25519 签名、nginx/Agent 日志路径与网卡名白名单、公开端点脱敏。
- **套餐到期也能登录续费**：到期账号（`expired` / `suspended+auto_expired`，含历史遗留）可正常登录与刷新令牌，但订阅数据（`/nodes`、`/sub`）仍然拒绝；真正的封禁语义不变。
- **配额策略可配置**：套餐与规格可选「续费累加 / 到期清空 / 续费重置」，规格留空继承套餐；新增每月自动重置巡检（`quota_reset_cycle=monthly`），到期按策略清零。
- **套餐可隐藏**：新增「在门户展示」开关，自用套餐不出现在客户端列表，也不能被新购/升级。
- **礼品卡闭环**：套餐卡绑定规格并保存价格快照，门户输入卡号自动带出对应套餐；单张建卡补批次号；修复卡密兑换把价格当规格 ID、流量包卡无法支付、备注卡号为空等问题。
- **门户修复**：余额行/充值按钮默认关闭且与开关状态一致；导航默认关闭只迁移一次（重启不再覆盖管理员设置）；存量模板自动补礼品卡预览与流量包卡号。
- **支付站点**：修复站点 ID 复用导致回调恒 `invalid signature`（旧密钥残留）、套餐支付产生重复计划订单、站点支付写虚假余额消费流水；删除站点时清理密钥/回调事件/重放 nonce。
- **删除客户级联清理**：订阅、订单、流水、工单、推荐、白名单等 20+ 张从属表在同一事务内清理，避免 SQLite 复用 ID 后新客户看到旧数据。
- **节点 ID 复用**：删除/新建节点时清理节点级子表并补默认路由，修复新节点继承旧配置、没有默认路由。
- **导出 CSV 多语言**：充值卡/充值订单/余额流水导出支持 `?lang=`，简体/繁体按语言输出，其余语言输出英文。
- **管理端错误消息统一英文**（52 处），并新增「核心服务异常」悬浮明细，可直接看到哪台节点的哪个核心异常。

### English

- **Security audit v7 wrapped up**: bootstrap tokens moved to request headers, Agent bootstrap no longer defaults to TOFU, ed25519 signatures for updates, allowlists for nginx/Agent log paths and interface names, redacted public endpoints.
- **Expired plans can still log in to renew**: expired accounts (`expired`, `suspended+auto_expired`, plus legacy rows) can log in and refresh tokens, while subscription data (`/nodes`, `/sub`) stays blocked; real bans are unchanged.
- **Configurable quota policy**: per plan and per variant you can choose accumulate on renewal, clear on expiry, or reset on renewal (variant falls back to plan); added a monthly reset scheduler.
- **Hide plans from the portal**: a new toggle keeps internal plans out of the client list and blocks new purchases/upgrades.
- **Gift card fixes**: cards are bound to a variant with a price snapshot; the portal picks the matching plan from the card code; single-card creation gets a batch ID; fixed redemption treating price as variant ID, traffic-pack cards being unusable, and empty masked card numbers in remarks.
- **Portal fixes**: balance row and charge button default to off and match their toggles; default-off navigation migrates only once; existing templates get the gift-card preview and traffic-pack payload patches.
- **Payment sites**: fixed reused site IDs keeping stale secrets (callback always `invalid signature`), duplicate plan orders on site payments, and phantom balance consumption entries; deleting a site now purges secrets, callback events and replay nonces.
- **Cascade cleanup on client deletion**: 20+ child tables are removed in one transaction so a reused SQLite ID can no longer surface another client's data.
- **Node ID reuse**: node-scoped tables are purged on delete/create and baseline routing is restored, fixing inherited config and missing default routes on new nodes.
- **Localized CSV exports**: card/order/balance exports accept `?lang=`; Simplified/Traditional Chinese per locale, everything else in English.
- **Admin error messages unified to English** (52 places), plus a hover detail on the dashboard's abnormal core count showing exactly which node and core failed.

### Русский

- **Завершён аудит безопасности v7**: токены установки передаются в заголовке, bootstrap Agent больше не использует TOFU по умолчанию, подписи ed25519 для обновлений, белые списки путей логов и имён интерфейсов, обезличивание публичных эндпоинтов.
- **Истёкшие тарифы могут войти и продлить**: аккаунты со статусом `expired` / `suspended+auto_expired` (включая старые записи) входят и обновляют токены, но данные подписки (`/nodes`, `/sub`) по-прежнему недоступны; реальные блокировки не изменились.
- **Настраиваемая политика квоты**: для тарифа и варианта можно выбрать накопление при продлении, очистку при истечении или сброс при продлении; добавлен ежечасный планировщик месячного сброса.
- **Скрытие тарифов из портала**: новый переключатель убирает внутренние тарифы из списка клиентов и запрещает покупку/апгрейд.
- **Исправления подарочных карт**: карта привязана к варианту и хранит снимок цены; портал подставляет нужный тариф по коду; одиночная карта получает batch ID; исправлены подмена цены на ID варианта, неработающие карты трафика и пустой маскированный номер в примечании.
- **Исправления портала**: строка баланса и кнопка пополнения по умолчанию выключены и соответствуют переключателям; миграция «по умолчанию выключенных» пунктов меню выполняется один раз; существующие шаблоны получают патчи предпросмотра карты и оплаты трафика.
- **Платёжные сайты**: исправлены повторное использование ID сайта со старым секретом (вечный `invalid signature`), дубли заказов тарифа и фиктивные списания баланса; при удалении сайта очищаются секреты, события колбэков и nonce.
- **Каскадное удаление клиента**: 20+ дочерних таблиц удаляются в одной транзакции, поэтому повторно использованный ID SQLite больше не показывает чужие данные.
- **Повторное использование ID узла**: при удалении/создании очищаются таблицы уровня узла и восстанавливается базовая маршрутизация.
- **Многоязычный экспорт CSV**: карты/заказы/баланс принимают `?lang=`; китайский по локали, остальные языки — английский.
- **Ошибки админки переведены на английский** (52 места); у счётчика сбоев ядра появилась подсказка с конкретным узлом и ядром.
