# Subscription API (public)

> Languages: [简体中文](subscription.md) · English · [繁體中文](subscription.zh-TW.md) · [Русский](subscription.ru.md) · [日本語](subscription.ja.md) · [한국어](subscription.ko.md) · [Deutsch](subscription.de.md) · [Français](subscription.fr.md) · [Español](subscription.es.md) · [Português](subscription.pt.md) · [Türkçe](subscription.tr.md) · [Bahasa Indonesia](subscription.id.md) · [ไทย](subscription.th.md) · [Tiếng Việt](subscription.vi.md) · [العربية](subscription.ar.md) · [فارسی](subscription.fa.md)

Fetches a user's subscription node list. **This is the most-used endpoint for end users**; no headers are required — access is granted by the token in the URL.

## 1. Endpoint

| Deployment | URL |
|---|---|
| Main panel | `GET https://<panel-domain>/sub/<token>` |
| Dedicated subscription port | `GET https://<sub-domain>:<port>/<token>` (no `/sub` prefix) |

`<token>` is the unique access token of a subscription, generated by the admin side (visible under “My subscriptions” in the portal).

## 2. Query parameters

| Parameter | Description |
|---|---|
| `format` | Output format; overrides the subscription default. See below |
| `config` | Configuration template name (defined under “Subscription formats” in the admin UI). Must use the same format as this request's `format`, otherwise it is ignored |
| `platform` | Match a configuration template by platform name (used when `config` is omitted); the format must also match |

### Supported `format` values

| Value | Output | Clients |
|---|---|---|
| `base64_uri` (default) | Newline-joined share links, base64-encoded as a whole | V2RayN, Shadowrocket, Surge and other generic clients |
| `raw_uri` | Newline-joined share links, plain text | Clients that need plain links / debugging |
| `mihomo_yaml` | Full Clash/Mihomo YAML configuration (with proxy-groups, rules) | Clash.Meta / mihomo / Clash Verge Rev |
| `mihomo_proxies_yaml` | YAML with only the `proxies:` node list | mihomo proxy-provider source (with scheduled refresh) |
| `singbox_json` | Full sing-box JSON configuration | sing-box / SFI / FLClash (sing-box core) |
| `xray_json` | Full Xray JSON configuration | Xray-core |

> Protocol/format compatibility applies: for example, `anytls` only appears in sing-box/Mihomo formats; REALITY nodes on a sing-box server do not appear in Xray/sing-box JSON subscriptions. Nodes the client cannot recognize are dropped automatically instead of failing the whole subscription.

## 3. Response headers

| Header | Example | Description |
|---|---|---|
| `Subscription-Userinfo` | `upload=1024; download=2048; total=1073741824; expire=1760000000` | Usage and expiry (bytes / Unix seconds). **Also sent on 403**, so clients can show the remaining allowance |
| `Profile-Update-Interval` | `6` | Suggested refresh interval (hours) |
| `Profile-Title` | `CoreFusion` | Profile name (shown by Clash Verge Rev / V2RayN, etc.) |
| `Profile-Web-Page-Url` | `https://…/portal` | Portal page link (“open web page” in clients) |
| `Content-Type` | Per format: `text/plain` / `text/yaml` / `application/json` | |
| `Content-Disposition` | `attachment; filename="subscription.txt"` | |

## 4. Status codes

| HTTP | code | Meaning |
|---|---|---|
| 200 | — | Normal (body is the subscription rendered in `format`) |
| 400 | `MISSING_TOKEN` | No token in the URL |
| 403 | (plain text) | Subscription suspended / expired / inactive. The message is localized (zh/en/ja/ko) via `Accept-Language` and is a one-line reason |
| 404 | `SUBSCRIPTION_NOT_FOUND` | Token does not exist |

> Revoked subscriptions are treated as non-existent (404).

## 5. Examples

```bash
# 1) Fetch with the default format
curl -L "https://panel.example.com/sub/abcd1234efgh5678"

# 2) Request Mihomo YAML with the "clash-global" config template
curl -L "https://panel.example.com/sub/abcd1234efgh5678?format=mihomo_yaml&config=clash-global"

# 3) Node list only (for a mihomo proxy-provider)
curl -L "https://panel.example.com/sub/abcd1234efgh5678?format=mihomo_proxies_yaml"

# 4) Check usage (headers only)
curl -sI "https://panel.example.com/sub/abcd1234efgh5678" | grep -i subscription-userinfo
```

Clash/Mihomo dynamic subscription (periodic refresh):

```yaml
proxy-providers:
  subscription-nodes:
    type: http
    url: "https://panel.example.com/sub/abcd1234efgh5678?format=mihomo_proxies_yaml"
    interval: 3600
    health-check:
      enable: true
      url: https://www.gstatic.com/generate_204
      interval: 300

proxy-groups:
  - name: PROXY
    type: select
    use:
      - subscription-nodes
```

## 6. Notes

- **Format and config are tightly coupled**: the template selected by `config`/`platform` must match this request's `format`; mismatched templates are ignored — this prevents injecting Mihomo rules into sing-box/Xray JSON.
- **Rate limiting**: the subscription endpoint has its own limit (`SubscribeRateLimit`); abusive clients are rejected.
- **Access log**: every fetch records IP / UA / CDN information, visible under “Subscription access log” in the admin UI.
- Without a domain configured on a dedicated subscription port, the request's `X-Forwarded-Proto` / `X-Forwarded-Host` are used; make sure your reverse proxy forwards both headers.
