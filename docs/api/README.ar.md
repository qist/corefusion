## 1. المنافذ وعناوين URL الأساسية

يمكن للوحة الكشف عن ثلاثة محركات في نفس الوقت، ومشاركة قاعدة بيانات واحدة:

| المحرك | الوصول الافتراضي | الغرض |
|---|---|---|
| اللوحة الرئيسية | `https://<domain>/api/v1` | الواجهة الخلفية للمشرف + البوابة + الاشتراكات |
| محرك الاشتراك (منفذ مخصص) | `https://<domain>:<port>/:token` | جلب الاشتراك عالي التزامن، بدون بادئة `/sub` |
| محرك البوابة (منفذ مخصص) | `https://<portal-domain>[:port]/api/v1` | بوابة العميل فقط، الصفحات في `/` |

> يجب أن يقوم الوكيل العكسي بإعادة توجيه مسارات الصفحة و`/api/v1`؛ يتشرف `X-Forwarded-Proto` / `X-Forwarded-Host` باستعادة المخطط والمجال الحقيقيين.

## 2. المصادقة (ثلاثة أنواع، غير قابلة للتبديل)

| مصادقة | بيانات الاعتماد | ينطبق على |
|---|---|---|
| **مصادقة المشرف** | `Authorization: Bearer <admin_token>` (من `/api/v1/auth/login`) | المشرف API |
| **مصادقة العميل** | `Authorization: Bearer <client_token>` (من `/api/v1/client-auth/login`) | بوابة API |
| ** رمز الاشتراك ** | الرمز المميز في URL: `/sub/<token>` | جلب الاشتراك، بدون رأس |

- رموز وصول العميل تدوم 24 ساعة، ورموز التحديث 7 أيام؛ يحتوي JWT على `tv` (token_version)، لذا فإن تسجيل الخروج/تسجيل الخروج القسري يبطل جميع الرموز المميزة القديمة.
- أدوار المشرف: `admin` / `operator` / `super_admin`؛ تتطلب بعض عمليات الكتابة `RequireRole(RoleAdmin)` أو أعلى.

## 3. تنسيق الاستجابة

النجاح (معظم نقاط النهاية):

```json
{ "code": 0, "data": { ... }, "message": "ok" }
```

قائمة نقاط النهاية (بعضها) تُرجع `{ "items": [...], "total": N }` أو مصفوفة مجردة (مذكورة لكل نقطة نهاية أدناه).

الأخطاء (HTTP 4xx/5xx):

```json
{ "code": "ERROR_CODE", "message": "human-readable description", "request_id": "…", "can_retry": false }
```

**المبالغ هي أعداد صحيحة بالسنت**: `990` = ¥9.90 (`currency: "CNY"`).
**حركة المرور بالبايت**: تستخدم الطلبات والاستجابات وحدات البايت.

## 4. حدود المعدل ووضع الصيانة

- نقاط النهاية العامة (`/api/v1/public/*`، `/sub/*`، الاشتراك/تسجيل الدخول) محدودة السعر؛
- يستخدم تسجيل الدخول أيضًا `LoginRateLimit`، ويستخدم جلب الاشتراك `SubscribeRateLimit`؛
- في وضع الصيانة، تقوم نقاط النهاية العامة والاشتراكات بإرجاع رسالة صيانة؛ المشرف API لم يتأثر.

## 5. مسارات صفحة الواجهة الأمامية (وليس API)

تقوم هذه المسارات بإرجاع أصول HTML/ثابتة وتقع خارج مستندات API؛ مدرجة بحيث يمكن استبعادها أثناء التكامل:

| الطريقة | المسار | الوصف |
|---|---|---|
| GET | `/` | لوحة الإدارة SPA (بعد تسجيل الدخول) |
| GET | `/p` | HTML للبوابة (`/` على محرك بوابة مخصص) |
| GET | `/:token` | جلب الاشتراك على منفذ مخصص (بدون بادئة `/sub`، نفس دلالات `/sub/:token`) |
| GET | `/static/:file` | الأصول الثابتة للواجهة الأمامية |
