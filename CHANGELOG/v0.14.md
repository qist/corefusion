## v0.14.1 — 2026-11-27

> 新增订阅短链（自动按格式 × 配置展开）；sing-box / Xray 订阅合并 inbounds；节点名自动脱敏与去重，proxy 组始终存在；新增 mihomo / sing-box / Xray 客户端模板文档。

### 中文

- **订阅短链（新）**：每条订阅可生成 20 位随机短码，链接形如 `https://<订阅域名>/<code>`，直接返回订阅正文（不 302），与长链接共用同一套授权/渲染链路；订阅吊销、token 轮换、短链禁用/过期都会立即失效。管理端「订阅中心 → 短链」可创建、复制、启停、轮换、删除，并记录命中次数与 `short_link_id`。
- **短链自动展开**：按套餐可见的「格式 × 配置（× providers）」幂等补齐，门户/客户端详情直接拿 URL，不再出现「短链 + `?format=&config=`」；无配置的 sing-box / Xray 不再展示多余条目。
- **sing-box / Xray 订阅合并 inbounds**：此前只合并 `log/dns/route/experimental`（Xray 为 `log/dns/routing/policy`），生成的配置没有监听端口；现在 `inbounds` 也会合并，订阅可直接被客户端加载。
- **节点名统一处理**：自动名（`inbound-<协议>-<端口>`）按入站 tag 脱敏，其它语言（中文/日文/俄文/波斯文等）的 remark 原样保留；同名节点追加 `-2/-3` 去重，避免 sing-box / Xray 因 outbound tag 重复整份拒载。
- **proxy 组始终存在**：节点名预占 `proxy` / `direct` / `block`，每次订阅都会注入 `tag: proxy` 的 selector（sing-box）/ balancer（Xray），规则可直接引用，无需手动改 `final` / `routing`。
- **客户端模板文档**：新增 `docs/mihomo-templates`（Windows / Android / OpenClash，含 22 端口独立 `🖥️ SSH` 组）、`docs/singbox-templates`、`docs/xray-templates`（服务端模板 + 可直接运行的 `standalone.json`），均提供简中 / English / Русский / فارسی 四种语言。

### English

- **Subscription short links (new)**: each subscription can get a 20-character code, e.g. `https://<sub-domain>/<code>`, returning the body directly (no 302) and sharing the same authorization/rendering path as the long URL; revocation, token rotation, disabled/expired links fail immediately. The admin can create, copy, enable/disable, rotate and delete links, and hit counts plus `short_link_id` are recorded.
- **Automatic short-link expansion**: links are generated idempotently for every visible "format × config (× providers)" combination, so portal/client pages use the URLs directly — no more `short link + ?format=&config=`. Config-less sing-box / Xray entries are no longer shown.
- **sing-box / Xray subscriptions merge `inbounds`**: previously only `log/dns/route/experimental` (`log/dns/routing/policy` for Xray) were merged, leaving generated configs without listeners; `inbounds` is now merged so subscriptions load as-is.
- **Unified node naming**: auto-generated names (`inbound-<proto>-<port>`) are sanitized to the protocol, while remarks in any language (Chinese/Japanese/Russian/Persian, …) are kept verbatim; duplicates get `-2/-3` so sing-box / Xray never reject the config for duplicate outbound tags.
- **The `proxy` group always exists**: node names reserve `proxy` / `direct` / `block`, and every subscription injects a `tag: proxy` selector (sing-box) / balancer (Xray); rules can reference it without editing `final` / `routing`.
- **Client template docs**: new `docs/mihomo-templates` (Windows / Android / OpenClash, with a dedicated `🖥️ SSH` group for port 22), `docs/singbox-templates` and `docs/xray-templates` (server template + runnable `standalone.json`), each in zh-CN / English / Русский / فارسی.

### Русский

- **Короткие ссылки подписки (новое)**: для каждой подписки можно создать 20-символьный код, например `https://<домен>/<code>`; ответ отдаётся напрямую (без 302) и использует тот же путь авторизации/рендеринга, что и длинная ссылка. Отзыв подписки, ротация токена, отключение/истечение ссылки действуют сразу. В админке можно создавать, копировать, включать/отключать, ротировать и удалять ссылки; сохраняются счётчик обращений и `short_link_id`.
- **Автоматическое развёртывание коротких ссылок**: ссылки идемпотентно создаются для всех видимых комбинаций «формат × конфигурация (× providers)», поэтому портал и карточка клиента используют готовый URL — без `short link + ?format=&config=`. Лишние записи sing-box / Xray без конфигурации больше не показываются.
- **Подписки sing-box / Xray объединяют `inbounds`**: раньше объединялись только `log/dns/route/experimental` (для Xray — `log/dns/routing/policy`), и в конфиге не было слушающих портов; теперь `inbounds` тоже объединяется, и подписку можно загрузить сразу.
- **Единая обработка имён узлов**: автоимена (`inbound-<протокол>-<порт>`) очищаются до протокола, а remark на любом языке (китайский/японский/русский/персидский и др.) сохраняется как есть; дубликаты получают `-2/-3`, чтобы sing-box / Xray не отклоняли конфиг из-за повторяющихся outbound tag.
- **Группа `proxy` всегда присутствует**: имена узлов резервируют `proxy` / `direct` / `block`, и каждая подписка получает `tag: proxy` — selector (sing-box) / balancer (Xray); правила ссылаются на него без правки `final` / `routing`.
- **Документация шаблонов**: добавлены `docs/mihomo-templates` (Windows / Android / OpenClash, отдельная группа `🖥️ SSH` для порта 22), `docs/singbox-templates` и `docs/xray-templates` (серверный шаблон + готовый `standalone.json`) на четырёх языках.

### فارسی

- **لینک کوتاه اشتراک (جدید)**: هر اشتراک می‌تواند یک کد ۲۰ کاراکتری بگیرد، مثلاً `https://<domain>/<code>`، که بدنه را مستقیم برمی‌گرداند (بدون 302) و همان مسیر احراز/رندر لینک بلند را دارد؛ لغو اشتراک، چرخش توکن و غیرفعال/منقضی شدن لینک فوراً اثر می‌کند. در پنل می‌توان ساخت، کپی، فعال/غیرفعال، چرخش و حذف کرد و تعداد بازدید و `short_link_id` ثبت می‌شود.
- **تولید خودکار لینک‌های کوتاه**: لینک‌ها به‌صورت idempotent برای همه ترکیب‌های «فرمت × پیکربندی (× providers)» ساخته می‌شوند تا پورتال و کارت مشتری مستقیماً از URL استفاده کنند و دیگر «short link + ?format=&config=» دیده نشود. موارد بدون پیکربندی برای sing-box / Xray دیگر نمایش داده نمی‌شوند.
- **ادغام `inbounds` در اشتراک sing-box / Xray**: قبلاً فقط `log/dns/route/experimental` (برای Xray: `log/dns/routing/policy`) ادغام می‌شد و پیکربندی بدون پورت شنود بود؛ اکنون `inbounds` هم ادغام می‌شود و اشتراک مستقیماً قابل بارگذاری است.
- **یکسان‌سازی نام گره‌ها**: نام‌های خودکار (`inbound-<protocol>-<port>`) به نام پروتکل ساده می‌شوند و remark به هر زبان (چینی/ژاپنی/روسی/فارسی و …) دست‌نخورده می‌ماند؛ نام‌های تکراری `-2/-3` می‌گیرند تا sing-box / Xray به‌خاطر tag تکراری کل پیکربندی را رد نکند.
- **گروه `proxy` همیشه وجود دارد**: نام گره‌ها `proxy` / `direct` / `block` را رزرو می‌کنند و هر اشتراک یک `tag: proxy` تزریق می‌کند — selector در sing-box و balancer در Xray؛ قواعد بدون ویرایش `final` / `routing` به آن اشاره می‌کنند.
- **مستندات قالب‌های کلاینت**: `docs/mihomo-templates` (Windows / Android / OpenClash با گروه اختصاصی `🖥️ SSH` برای پورت 22)، `docs/singbox-templates` و `docs/xray-templates` (قالب سرور + `standalone.json` آماده اجرا) در چهار زبان اضافه شد.

## v0.14.0 — 2026-11-26

> 新增节点安全体检（含 IPv6 与配置覆盖检测）；CF 探测支持指定执行节点与出口网卡、远程安装核心；链式代理探测与优选探测定时互斥，检测连通性按 IP / 域名分开。

### 中文

- **节点安全体检（新）**：节点详情 →「体检」，只读采集系统 / SSH / 防火墙 / 内核参数并给出分级建议（high / warn / info / ok），支持结果缓存（10 分钟）、手动刷新与完整 Markdown 文档（可复制 / 下载 / 在线查看）。
- **建议命令会落盘**：内核参数写入 `/etc/sysctl.d/99-corefusion.conf`（按 key 去重后追加并执行 `sysctl --system`），SSH 写入 `/etc/ssh/sshd_config.d/00-corefusion-*.conf`，BBR 模块写入 `/etc/modules-load.d/`，重启后仍然生效。
- **配置覆盖检测（CFG-01/02）**：逐个列出 sysctl key 的最后生效位置（`/etc/sysctl.conf` 永远最后加载）与 sshd 的首个命中位置（先匹配生效，drop-in 需 `00-` 前缀且 `Include` 必须在相关指令之前），避免「改了自己的文件却不生效」。
- **IPv6 体检（IPV6-01~06）**：仅当节点存在全局 IPv6 时检查 forwarding / ICMPv6 重定向 / 源路由 / 隐私扩展 / 邻居表 / 路由缓存上限；`singbr0`、`wg0`、`tun0` 等隧道地址单独标记为 `tun`，不计入公网判断，也不建议手工修改。
- **root 登录语义修正**：密码与键盘交互认证都关闭时，`PermitRootLogin yes` 判为 ok（只能密钥登录），不再提示关闭 root。
- **CF 探测支持执行节点与出口网卡**：临时核心可在任意 Agent 上执行，网卡列表取自该节点；xray / sing-box / mihomo 均支持绑定出口网卡，留空走系统默认路由。
- **拨号核心按执行节点判断**：只列出该节点实际安装的核心与版本；支持在远程节点直接安装 / 重装（由 Agent 下载，无需 SSH），缺核心时报错并给出该节点可用核心。
- **链式代理探测**：原「链路探测」改名；可继承或独立设置间隔与拨号核心；与优选探测**定时互斥**——开启后定时优选探测暂停，手动「检测连通性」不受影响。
- **检测连通性按类型分开**：CF IP 池页只更新优选 IP，分享域名页只更新优选域名，互不影响；不带类型时仍检测全部（兼容旧调用）。
- **文档**：新增 16 语言 `docs/node-tuning.*.md`，体检弹窗可直接跳转；`USER-GUIDE` 增加节点安全体检章节。

> 升级提示：本次 Agent 协议新增链路探测命令，**面板与 Agent 必须同版本升级**，否则在节点上执行探测会报错。

### English

- **Node security checkup (new)**: Node details → Checkup performs read-only collection of system, SSH, firewall and kernel settings and returns graded advice (high / warn / info / ok), with 10-minute caching, manual refresh and a full Markdown report (copy / download / view online).
- **Suggested commands persist**: kernel parameters are written to `/etc/sysctl.d/99-corefusion.conf` (de-duplicated per key, then `sysctl --system`), SSH to `/etc/ssh/sshd_config.d/00-corefusion-*.conf` and the BBR module to `/etc/modules-load.d/`; all survive a reboot.
- **Precedence check (CFG-01/02)**: lists the last effective definition per sysctl key (`/etc/sysctl.conf` is always loaded last) and the first matching sshd directive (first match wins; drop-ins need the `00-` prefix and `Include` must come before those directives), so "I changed my file but nothing happened" becomes visible.
- **IPv6 checks (IPV6-01~06)**: only when the node has a global IPv6 — forwarding, ICMPv6 redirects, source routing, privacy extensions, neighbour table and route cache limit. Tunnel addresses such as `singbr0` / `wg0` / `tun0` are labelled `tun`, excluded from the public-IPv6 decision and never edited by hand.
- **root login semantics fixed**: with password and keyboard-interactive authentication both off, `PermitRootLogin yes` is judged ok (key-only); root is no longer flagged for disabling.
- **Probe execution node and egress NIC**: the temporary core can run on any Agent and the NIC list comes from that node; xray / sing-box / mihomo all support binding an egress interface (empty = system default route).
- **Dialer cores resolved per execution node**: only cores actually installed on that node are listed with versions; install / reinstall runs on the remote node through the Agent (no SSH), and a missing core produces a clear error that lists the available ones.
- **Chain proxy probe**: renamed from "link probe"; interval and dialer can be inherited or set independently; mutually exclusive with the preferred-IP probe **on the schedule** — scheduled preferred-IP probing pauses when it is enabled, while manual "Check connectivity" still works.
- **Check connectivity is per list**: the CF IP pool page only updates preferred IPs and the shared-domain page only updates CF domains; without a kind both are still checked (backwards compatible).
- **Docs**: 16-language `docs/node-tuning.*.md` with a direct link from the checkup dialog; `USER-GUIDE` gained a node security checkup chapter.

> Upgrade note: this release adds a chain-probe command to the Agent protocol, so **panel and Agent must be upgraded together**; otherwise probing on nodes will fail.

### Русский

- **Проверка безопасности узла (новое)**: в карточке узла → «Проверка» — только чтение системы, SSH, фаервола и параметров ядра, оценка high / warn / info / ok, кэш 10 минут, ручное обновление и полный отчёт Markdown (копировать / скачать / открыть онлайн).
- **Рекомендованные команды сохраняются**: параметры ядра — `/etc/sysctl.d/99-corefusion.conf` (с удалением дублей и `sysctl --system`), SSH — `/etc/ssh/sshd_config.d/00-corefusion-*.conf`, модуль BBR — `/etc/modules-load.d/`; всё переживает перезагрузку.
- **Проверка приоритета (CFG-01/02)**: для каждого ключа sysctl показано последнее действующее определение (`/etc/sysctl.conf` всегда последний), для sshd — первое совпавшее указание (побеждает первое; drop-in нужен префикс `00-`, а `Include` должен стоять до этих директив).
- **Проверки IPv6 (IPV6-01~06)**: только при наличии глобального IPv6 — forwarding, редиректы ICMPv6, source routing, privacy extensions, таблица соседей и лимит кэша маршрутов. Адреса туннелей (`singbr0` / `wg0` / `tun0`) помечаются как `tun`, не считаются публичными и не редактируются вручную.
- **Семантика входа root**: при отключённой парольной и keyboard-interactive аутентификации `PermitRootLogin yes` считается нормой (только по ключу), отключать root не требуется.
- **Узел выполнения и сетевой интерфейс**: временное ядро может работать на любом Agent, список интерфейсов берётся с этого узла; xray / sing-box / mihomo поддерживают привязку исходящего интерфейса (пусто — маршрут по умолчанию).
- **Ядра определяются по узлу выполнения**: показываются только реально установленные там ядра с версиями; установка и переустановка выполняются на удалённом узле через Agent (без SSH), при отсутствии ядра выдаётся понятная ошибка со списком доступных.
- **Цепная проверка прокси**: переименована; интервал и ядро можно наследовать или задавать отдельно; по расписанию несовместима с проверкой предпочтительных IP (ручная проверка работает).
- **Проверка связи по спискам**: страница пула CF IP обновляет только IP, страница доменов — только домены.
- **Документация**: 16 языков `docs/node-tuning.*.md` и новый раздел в `USER-GUIDE`.

> При обновлении: в протокол Agent добавлена команда цепной проверки, поэтому **панель и Agent нужно обновлять вместе**.

### فارسی

- **بررسی امنیتی گره (جدید)**: در جزئیات گره → «بررسی» — جمع‌آوری فقط‌خواندنی سیستم، SSH، فایروال و پارامترهای هسته با درجه‌بندی high / warn / info / ok، کش ۱۰ دقیقه‌ای، بازخوانی دستی و گزارش کامل Markdown (کپی / دانلود / مشاهده آنلاین).
- **دستورهای پیشنهادی ماندگار می‌شوند**: پارامترهای هسته در `/etc/sysctl.d/99-corefusion.conf` (حذف تکراری‌ها و سپس `sysctl --system`)، SSH در `/etc/ssh/sshd_config.d/00-corefusion-*.conf` و ماژول BBR در `/etc/modules-load.d/`؛ پس از ری‌استارت باقی می‌مانند.
- **بررسی اولویت تنظیمات (CFG-01/02)**: برای هر کلید sysctl آخرین تعریف مؤثر (`/etc/sysctl.conf` همیشه آخر) و برای sshd نخستین دستور منطبق (اولین تطابق برنده است؛ drop-in به پیشوند `00-` و قرار گرفتن `Include` پیش از این دستورها نیاز دارد) نمایش داده می‌شود.
- **بررسی‌های IPv6 (IPV6-01~06)**: تنها وقتی گره IPv6 عمومی دارد — forwarding، ریدایرکت ICMPv6، source routing، افزونه‌های حریم خصوصی، جدول همسایه‌ها و سقف کش مسیر. نشانی تونل‌ها (`singbr0` / `wg0` / `tun0`) با برچسب `tun` جدا می‌شود، عمومی محسوب نمی‌شود و دستی ویرایش نمی‌شود.
- **معنای ورود root**: وقتی احراز هویت با گذرواژه و keyboard-interactive خاموش است، `PermitRootLogin yes` تأیید می‌شود (فقط با کلید) و دیگر پیشنهاد خاموش‌کردن root داده نمی‌شود.
- **گره اجرا و کارت شبکه خروجی**: هستهٔ موقت می‌تواند روی هر Agent اجرا شود و فهرست کارت‌های شبکه از همان گره گرفته می‌شود؛ xray / sing-box / mihomo از اتصال به کارت شبکه خروجی پشتیبانی می‌کنند (خالی = مسیر پیش‌فرض).
- **انتخاب هسته بر اساس گره اجرا**: فقط هسته‌های واقعاً نصب‌شده روی همان گره با نسخه فهرست می‌شوند؛ نصب/نصب مجدد روی گرهٔ دور از طریق Agent (بدون SSH) انجام می‌شود و نبود هسته خطای روشن با فهرست هسته‌های موجود می‌دهد.
- **بررسی پروکسی زنجیره‌ای**: تغییر نام یافته؛ بازه و هسته قابل ارث‌بری یا تنظیم مستقل است و در زمان‌بندی با بررسی IPهای منتخب ناسازگار است (بررسی دستی همچنان کار می‌کند).
- **بررسی اتصال به‌تفکیک فهرست**: صفحهٔ استخر CF IP فقط IPها و صفحهٔ دامنه‌های اشتراکی فقط دامنه‌ها را به‌روز می‌کند.
- **مستندات**: `docs/node-tuning.*.md` در ۱۶ زبان و فصل جدید در `USER-GUIDE`.

> یادآوری به‌روزرسانی: فرمان بررسی زنجیره‌ای به پروتکل Agent اضافه شده است، بنابراین **پنل و Agent باید با هم به‌روزرسانی شوند**.
