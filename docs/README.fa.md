## اسناد طراحی

اسناد طراحی مواد داخلی (مالکیت معنوی اصلی) هستند و **توزیع نمی شوند** با این مخزن. در صورت نیاز با نگهدارنده تماس بگیرید.

> **حوزه**: برنامه مشتری (UI محلی، تصاحب TUN، سینی، ادغام چند اشتراک) یک محصول جداگانه است و خارج از محدوده این مخزن است. مستندات اینجا فقط سمت سرور (پانل / گره ها / تحویل اشتراک) را پوشش می دهد.
