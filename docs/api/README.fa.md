## 1. پورت ها و URL های پایه

این پنل می تواند سه موتور را به طور همزمان در معرض دید قرار دهد و یک پایگاه داده را به اشتراک بگذارد:

| موتور | دسترسی پیش فرض | هدف |
|---|---|---|
| پنل اصلی | `https://<domain>/api/v1` | مدیریت باطن + پورتال + اشتراک |
| موتور اشتراک (پورت اختصاصی) | `https://<domain>:<port>/:token` | واکشی اشتراک با همزمانی بالا، بدون پیشوند `/sub` |
| موتور پورتال (پورت اختصاصی) | `https://<portal-domain>[:port]/api/v1` | پورتال فقط مشتری، صفحات در `/` |

> پروکسی معکوس باید هر دو مسیر صفحه و `/api/v1` را ارسال کند. `X-Forwarded-Proto` / `X-Forwarded-Host` مفتخر به بازیابی طرح و دامنه واقعی هستند.

## 2. احراز هویت (سه نوع، غیر قابل تعویض)

| احراز هویت | اعتبارنامه | اعمال می شود |
|---|---|---|
| **احراز هویت مدیر** | `Authorization: Bearer <admin_token>` (از `/api/v1/auth/login`) | ادمین API |
| ** احراز هویت مشتری ** | `Authorization: Bearer <client_token>` (از `/api/v1/client-auth/login`) | پورتال API |
| **توکن اشتراک** | توکن در URL: `/sub/<token>` | واکشی اشتراک، بدون سرصفحه |

- توکن‌های دسترسی مشتری 24 ساعت دوام می‌آورند، توکن‌ها 7 روز به‌روزرسانی می‌شوند. JWT حاوی `tv` (نسخه_token) است، بنابراین خروج / خروج اجباری همه توکن‌های قدیمی را باطل می‌کند.
- نقش های مدیر: `admin` / `operator` / `super_admin`؛ برخی از عملیات نوشتن به `RequireRole(RoleAdmin)` یا بالاتر نیاز دارند.

## 3. فرمت پاسخ

موفقیت (بیشتر نقاط پایانی):

```json
{ "code": 0, "data": { ... }, "message": "ok" }
```

نقاط پایانی را فهرست کنید (برخی) `{ "items": [...], "total": N }` یا یک آرایه خالی (که در هر نقطه پایانی در زیر ذکر شده است) را برمی گرداند.

خطاها (HTTP 4xx/5xx):

```json
{ "code": "ERROR_CODE", "message": "human-readable description", "request_id": "…", "can_retry": false }
```

**مقدارها اعداد صحیح بر حسب سنت هستند**: `990` = 9.90 ¥ (`currency: "CNY"`).
**ترافیک بر حسب بایت است**: درخواست ها و پاسخ ها هر دو از بایت استفاده می کنند.

## 4. محدودیت های نرخ و حالت نگهداری

- نقاط پایانی عمومی (`/api/v1/public/*`، `/sub/*`، ثبت نام/ورود به سیستم) دارای نرخ محدود هستند.
- ورود به سیستم از `LoginRateLimit` نیز استفاده می‌کند، واکشی اشتراک از `SubscribeRateLimit` استفاده می‌کند.
- در حالت تعمیر و نگهداری، نقاط پایانی عمومی و اشتراک‌ها یک پیام تعمیر و نگهداری را برمی‌گردانند. مدیر API تحت تأثیر قرار نمی گیرد.

## 5. مسیرهای صفحه فرانت اند (نه API)

این مسیرها دارایی‌های HTML/static را برمی‌گردانند و خارج از اسناد API هستند. فهرست شده است تا بتوان آنها را در طول ادغام حذف کرد:

| روش | مسیر | توضیحات |
|---|---|---|
| GET | `/` | پنل مدیریت SPA (پس از ورود به سیستم) |
| GET | `/p` | پورتال HTML (`/` در موتور پورتال اختصاصی) |
| GET | `/:token` | واکشی اشتراک در یک پورت اختصاصی (بدون پیشوند `/sub`، معنایی مشابه با `/sub/:token`) |
| GET | `/static/:file` | دارایی های استاتیک Frontend |
