## 1. Порты и базовые URL-адреса

Панель может одновременно предоставлять доступ к трем движкам, используя одну базу данных:

| Двигатель | Доступ по умолчанию | Цель |
|---|---|---|
| Основная панель | `https://<domain>/api/v1` | Серверная часть администрирования + портал + подписки |
| Механизм подписки (выделенный порт) | `https://<domain>:<port>/:token` | Получение подписки с высокой степенью параллелизма, без префикса `/sub`. |
| Портальный движок (выделенный порт) | `https://<portal-domain>[:port]/api/v1` | Портал только для клиентов, страницы по адресу `/`. |

> Обратный прокси-сервер должен пересылать оба пути к страницам и `/api/v1`; `X-Forwarded-Proto`/`X-Forwarded-Host` имеют честь восстановить реальную схему и домен.

## 2. Аутентификация (три вида, не взаимозаменяемые)

| Авторизация | Полномочия | Применяется к |
|---|---|---|
| **Аутентификация администратора** | `Authorization: Bearer <admin_token>` (из `/api/v1/auth/login`) | Администратор API |
| **Аутентификация клиента** | `Authorization: Bearer <client_token>` (из `/api/v1/client-auth/login`) | Портал API |
| **Токен подписки** | Токен в URL: `/sub/<token>` | Получение подписки, без заголовка |

- Токены клиентского доступа действуют 24 часа, токены обновляются 7 дней; JWT содержит `tv` (token_version), поэтому выход из системы/принудительный выход делает недействительными все старые токены.
- Роли администратора: `admin`/`operator`/`super_admin`; для некоторых операций записи требуется `RequireRole(RoleAdmin)` или выше.

## 3. Формат ответа

Успех (большинство конечных точек):

```json
{ "code": 0, "data": { ... }, "message": "ok" }
```

Конечные точки списка (некоторые) возвращают `{ "items": [...], "total": N }` или пустой массив (отмечено для каждой конечной точки ниже).

Ошибки (HTTP 4xx/5xx):

```json
{ "code": "ERROR_CODE", "message": "human-readable description", "request_id": "…", "can_retry": false }
```

**Суммы указаны целыми числами в центах**: `990` = 9,90 иен (`currency: "CNY"`).
**Трафик измеряется в байтах**: запросы и ответы используют байты.

## 4. Ограничения скорости и режим обслуживания

- Общедоступные конечные точки (`/api/v1/public/*`, `/sub/*`, регистрация/вход) ограничены по скорости;
- Для входа также используется `LoginRateLimit`, для получения подписки используется `SubscribeRateLimit`;
- В режиме обслуживания общедоступные конечные точки и подписки возвращают сообщение обслуживания; администратор API не затрагивается.

## 5. Маршруты страниц внешнего интерфейса (не API)

Эти маршруты возвращают HTML/статические ресурсы и находятся за пределами документации API; перечислены, чтобы их можно было исключить во время интеграции:

| Метод | Путь | Описание |
|---|---|---|
| GET | `/` | SPA-панель администратора (после входа в систему) |
| GET | `/p` | HTML портала (`/` на специальном движке портала) |
| GET | `/:token` | Получение подписки на выделенном порту (без префикса `/sub`, та же семантика, что и у `/sub/:token`) |
| GET | `/static/:file` | Статические ресурсы фронтенда |
