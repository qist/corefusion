# sing-box subscription-format template

<sub>[简体中文](README.md) · English · [Русский](README.ru.md) · [فارسی](README.fa.md)</sub>

[`config.json`](./config.json) is the `config_json` of the **sing-box** subscription
format in the panel. It only contains client-side fixed sections:

```text
log / dns / inbounds / route / experimental
```

`outbounds` are generated by the panel from the subscription nodes, and a
`tag: proxy` **selector** is always injected. **The subscription always contains
`proxy`** — rules can reference it without manual edits. If a node is literally named
`proxy` / `direct` / `block`, it is renamed (`proxy-2`, …) to keep tags unique.

## 1. Upload

```text
Panel → Subscription format → New
  client_type: singbox
  format:      singbox_json
  content:     paste config.json
```

Subscription URL:

```text
https://<panel>/sub/<token>?format=singbox_json&config=<format>
```

> `inbounds` used to be dropped (only log/dns/route/experimental were merged).
> It is now merged, otherwise clients receive a config without listeners.

## 2. Subscribers and standalone use

- **Subscribers only need the subscription URL** — no panel account, no manual editing.
- **Without a panel**, use [`standalone.json`](./standalone.json): a complete config
  that passes `sing-box check`. Replace `node-example` in `outbounds`
  (placeholder `127.0.0.1:1080` socks5) with your own node.

## 3. Structure

| Section | Purpose |
| --- | --- |
| `inbounds` | `mixed` on `127.0.0.1:7890`; add TUN yourself if needed |
| `dns` | new DNS format (sing-box 1.12+): China DoH → `direct`, global DoH → `proxy` |
| `route.rule_set` | remote `.srs` from MetaCubeX: `cn`, `category-ads-all`, `geolocation-!cn`, `geoip/cn` |
| `route.rules` | ads → reject; STUN (3478/19302) → reject; China → direct; global → proxy |
| `route.final` | `proxy` (injected selector) |

## 4. DNS (new format)

```json
{ "type": "https", "tag": "dns-cn", "server": "223.5.5.5", "path": "/dns-query", "detour": "direct" }
```

The legacy `{"address": "...", "detour": "..."}` form was removed in sing-box 1.12.

## 5. TUN (optional)

```json
{
  "type": "tun",
  "tag": "tun-in",
  "address": ["172.19.0.1/30"],
  "auto_route": true,
  "strict_route": false,
  "stack": "system"
}
```

`stack` is deprecated in sing-box 1.15 but still works (WARN only).

## 6. Rule sets

```text
https://raw.githubusercontent.com/MetaCubeX/meta-rules-dat/sing/geo/geosite/<name>.srs
https://raw.githubusercontent.com/MetaCubeX/meta-rules-dat/sing/geo/geoip/<name>.srs
```

Clash `.txt`/`.yaml` rule sets cannot be consumed directly; convert them to `.srs`
first (`sing-box rule-set convert`).

## 7. Verify

```bash
curl -s "https://<panel>/sub/<token>?format=singbox_json&config=<format>" -o sb.json
sing-box check -c sb.json
# exit 0 = OK
```
