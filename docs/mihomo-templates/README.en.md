# mihomo subscription-format templates

<sub>[简体中文](README.md) · English · [Русский](README.ru.md) · [فارسی](README.fa.md)</sub>

Three templates: **Windows / Android / OpenClash (router)**.

They are the YAML stored in the panel under **Subscription format**: no `proxies`, no
`proxy-providers`. Nodes are generated by the panel per plan at render time.

| File | Client | Traffic capture |
| --- | --- | --- |
| [`mihomo-windows.yaml`](./mihomo-windows.yaml) | Clash Verge Rev / Mihomo Party / FlClash PC | `mixed-port` + system proxy |
| [`mihomo-android.yaml`](./mihomo-android.yaml) | Clash Meta for Android / FlClash | VPN/TUN created by the app |
| [`mihomo-openclash.yaml`](./mihomo-openclash.yaml) | OpenClash (OpenWrt) | redirect/tproxy, TUN optional |

## 1. How dynamic generation works

| Location | Meaning |
| --- | --- |
| `_hasExternalNodes: true` | "put external nodes in this group". Raw mode inlines node names; provider mode injects `use` |
| top-level `proxies:` | only special outbounds (e.g. `dns-out`); normal nodes are generated |
| top-level `proxy-providers:` | **do not add**: the panel ignores it (one YAML is shared by many plans) |
| `rules:` | exported by the panel after import; the template copy is only a reference |

```text
paste template → save as subscription format → client pulls /sub/<token>
    default      : nodes inlined into _hasExternalNodes groups
    ?providers=1 : proxy-providers emitted + groups get `use`
```

## 2. Import into the panel

1. Panel → **Subscription format** (mihomo config) → create/edit;
2. Paste the YAML → save;
3. Bind it to a plan and configure providers under **Plan → Subscription sources**.

Client URLs:

```text
https://<panel>/sub/<token>
https://<panel>/sub/<token>?format=mihomo_yaml&config=<format>&providers=1
```

## 3. SSH (port 22) only through chosen nodes

```yaml
- DST-PORT,22,🖥️ SSH,no-resolve

- name: 🖥️ SSH
  type: select
  proxies:
    - DIRECT
```

By default the group contains only `DIRECT` — no nodes are pulled in automatically.
To allow a specific node group:

```text
Panel → Plan → Subscription sources → group → sources
  group: 🖥️ SSH
  source: <node group, e.g. hysteria>
```

Result: `22 → 🖥️ SSH → use: [hysteria]` (only those nodes). Other groups are unaffected.

> Mapping is per plan (not in the template) and matches by **exact group name**.
> The old name was `ACCESS-DENIED`; after switching to `🖥️ SSH` update the mapping,
> otherwise port 22 falls back to `DIRECT`.

## 4. Rules and DNS

- `rule-providers` point to `https://rules.example.com/clash/Ruleset/...` — replace
  with your own rules library (public sources listed in the Chinese README).
- geodata uses the public MetaCubeX release:

```yaml
geox-url:
  geoip: "https://fastly.jsdelivr.net/gh/MetaCubeX/meta-rules-dat@release/geoip.dat"
  geosite: "https://fastly.jsdelivr.net/gh/MetaCubeX/meta-rules-dat@release/geosite.dat"
  mmdb: "https://fastly.jsdelivr.net/gh/MetaCubeX/meta-rules-dat@release/geoip.metadb"
```

- DNS uses public DoH only: Alibaba/Tencent for China, Google/Cloudflare for the rest.

## 5. Platform differences

| Item | Windows | Android | OpenClash |
| --- | --- | --- | --- |
| `allow-lan` | false | false | **true** |
| `ipv6` | false | true | true |
| `find-process-mode` | strict | strict | **"off"** (quote it, otherwise YAML turns it into `false`) |
| `tun` | not set (system proxy) | not set (app handles it) | **enabled**, `stack: system` |
| `external-controller` | `127.0.0.1:9090` | `127.0.0.1:9090` | `0.0.0.0:9090` |

## 6. Verify

```bash
curl -s "https://<panel>/sub/<token>?format=mihomo_yaml" -o test.yaml
mihomo -t -d <tmpdir> -f test.yaml
# configuration file ... test is successful
```
