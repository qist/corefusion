## 1. พอร์ตและ URL ฐาน

แผงควบคุมสามารถแสดงกลไกสามรายการพร้อมกันโดยใช้ฐานข้อมูลเดียว:

| เครื่องยนต์ | การเข้าถึงเริ่มต้น | วัตถุประสงค์ |
|---|---|---|
| แผงหลัก | `https://<domain>/api/v1` | แบ็กเอนด์ผู้ดูแลระบบ + พอร์ทัล + การสมัครสมาชิก |
| กลไกการสมัครสมาชิก (พอร์ตเฉพาะ) | `https://<domain>:<port>/:token` | การดึงข้อมูลการสมัครสมาชิกที่เกิดขึ้นพร้อมกันสูง ไม่มีคำนำหน้า `/sub` |
| กลไกพอร์ทัล (พอร์ตเฉพาะ) | `https://<portal-domain>[:port]/api/v1` | พอร์ทัลไคลเอ็นต์เท่านั้น หน้าที่ `/` |

> พร็อกซีย้อนกลับต้องส่งต่อทั้งเส้นทางเพจและ `/api/v1` `X-Forwarded-Proto` / `X-Forwarded-Host` รู้สึกเป็นเกียรติที่ได้กู้คืนโครงร่างและโดเมนจริง

## 2. การรับรองความถูกต้อง (สามชนิดไม่สามารถใช้แทนกันได้)

| การรับรองความถูกต้อง | หนังสือรับรอง | นำไปใช้กับ |
|---|---|---|
| **ผู้ดูแลระบบอนุมัติ** | `Authorization: Bearer <admin_token>` (จาก `/api/v1/auth/login`) | แอดมิน API |
| **การรับรองลูกค้า** | `Authorization: Bearer <client_token>` (จาก `/api/v1/client-auth/login`) | พอร์ทัล API |
| **โทเค็นการสมัครสมาชิก** | โทเค็นใน URL: `/sub/<token>` | ดึงข้อมูลการสมัครสมาชิก ไม่มีส่วนหัว |

- โทเค็นการเข้าถึงไคลเอ็นต์มีอายุ 24 ชั่วโมง รีเฟรชโทเค็น 7 วัน JWT มี `tv` (token_version) ดังนั้นการออกจากระบบ / บังคับให้ออกจากระบบจะทำให้โทเค็นเก่าทั้งหมดเป็นโมฆะ
- บทบาทผู้ดูแลระบบ: `admin` / `operator` / `super_admin`; การดำเนินการเขียนบางอย่างต้องใช้ `RequireRole(RoleAdmin)` หรือสูงกว่า

## 3. รูปแบบการตอบกลับ

ความสำเร็จ (ปลายทางส่วนใหญ่):

```json
{ "code": 0, "data": { ... }, "message": "ok" }
```

รายการจุดสิ้นสุด (บางส่วน) ส่งคืน `{ "items": [...], "total": N }` หรืออาร์เรย์เปล่า (ระบุไว้ต่อจุดสิ้นสุดด้านล่าง)

ข้อผิดพลาด (HTTP 4xx/5xx):

```json
{ "code": "ERROR_CODE", "message": "human-readable description", "request_id": "…", "can_retry": false }
```

**จำนวนเงินเป็นจำนวนเต็มเป็นเซนต์**: `990` = ¥9.90 (`currency: "CNY"`)
**การรับส่งข้อมูลเป็นไบต์**: คำขอและการตอบกลับใช้ไบต์ทั้งคู่

## 4. ขีดจำกัดอัตราและโหมดการบำรุงรักษา

- จุดสิ้นสุดสาธารณะ (`/api/v1/public/*`, `/sub/*`, การสมัคร/ลงชื่อเข้าใช้) มีอัตราจำกัด
- การลงชื่อเข้าใช้ยังใช้ `LoginRateLimit` การดึงข้อมูลการสมัครสมาชิกใช้ `SubscribeRateLimit`
- ในโหมดการบำรุงรักษาปลายทางสาธารณะและการสมัครสมาชิกจะส่งคืนข้อความการบำรุงรักษา ผู้ดูแลระบบ API ไม่ได้รับผลกระทบ

## 5. เส้นทางส่วนหน้า (ไม่ใช่ API)

เส้นทางเหล่านี้ส่งคืนสินทรัพย์ HTML/คงที่ และอยู่นอกเอกสาร API ระบุไว้เพื่อให้สามารถยกเว้นได้ในระหว่างการรวมระบบ:

| วิธีการ | เส้นทาง | คำอธิบาย |
|---|---|---|
| GET | `/` | แผงผู้ดูแลระบบ SPA (หลังจากลงชื่อเข้าใช้) |
| GET | `/p` | พอร์ทัล HTML (`/` บนกลไกพอร์ทัลเฉพาะ) |
| GET | `/:token` | การดึงข้อมูลการสมัครสมาชิกบนพอร์ตเฉพาะ (ไม่มีคำนำหน้า `/sub`, ความหมายเดียวกันกับ `/sub/:token`) |
| GET | `/static/:file` | สินทรัพย์คงที่ส่วนหน้า |

## 6. ที่มาของความจริง
