# 通知模板变量说明

通知模板使用 `{变量名}` 占位符，发送时会被替换为实际值。本文档列出所有支持的变量、各事件的可用变量，以及自动触发规则。

## 一、模板类型与受众

| 受众 | 渠道 | 收件人 | 典型用途 |
|---|---|---|---|
| **面板使用者**（admin） | Telegram / Email | 管理员配置的渠道与收件人 | 节点告警、备份报告、系统公告 |
| **订阅者**（subscriber） | Email | 客户本人邮箱（系统自动按客户填充） | 余额不足、订阅到期提醒 |

## 二、通用变量

所有模板均可使用：

| 变量 | 说明 | 示例值 |
|---|---|---|
| `{time}` | 发送时间 | `2026-09-28 14:30:00` |
| `{user}` | 客户邮箱（订阅者模板）/ 用户标识 | `user@example.com` |
| `{message}` | 通知正文内容 | 系统维护公告正文 |

## 三、订阅者事件变量

### 订阅到期提醒（event_key = `subscription_expire`）

每日自动扫描，发给 7 天内到期的有效订阅客户：

| 变量 | 说明 | 示例值 |
|---|---|---|
| `{user}` | 客户邮箱 | `user@example.com` |
| `{expire_date}` | 订阅到期时间 | `2026-10-05 09:00` |
| `{days}` | 剩余天数 | `7` |
| `{time}` | 发送时间 | `2026-09-28 09:05:00` |

### 余额不足提醒（event_key = `balance_low`）

每日自动扫描，发给余额低于阈值的客户：

| 变量 | 说明 | 示例值 |
|---|---|---|
| `{user}` | 客户邮箱 | `user@example.com` |
| `{balance}` | 当前余额（元，自动保留两位小数） | `0.85` |
| `{time}` | 发送时间 | `2026-09-28 09:05:00` |

## 四、运维模板示例变量

面板使用者模板在点击「发送」做连通性测试时，会用以下示例值填充占位符：

| 变量 | 说明 | 示例值 |
|---|---|---|
| `{node}` | 节点名称 | `node-01` |
| `{backup_file}` | 备份文件名 | `corefusion-20260101-0900.tar.gz` |
| `{size}` | 文件大小 | `128MB` |
| `{domain}` | 域名 | `example.com` |
| `{expire_date}` | 到期日期 | `2026-10-12` |
| `{days}` | 剩余天数 | `14` |
| `{count}` | 数量 | `3` |

## 五、自动触发规则

- **触发时间**：面板启动 30 秒后执行一次首次扫描，之后每天 **09:05** 执行
- **订阅到期**：扫描 7 天内到期的有效订阅（`status=active`），客户状态也需为有效
- **余额不足**：扫描余额 ≤ 阈值的有效客户；阈值通过系统设置 `notify.balance_threshold` 配置，**单位为分**（默认 `100` = 1.00 元）
- **防重复**：同一客户、同一事件**每天最多发送一条**（`notification_send_logs` 按天去重）

## 六、节点健康监控（监控类通知）

按频率持续检查节点心跳，**状态发生变化才发通知，状态未变化的轮次全部静默跳过**：

| 设置键 | 说明 | 默认值 |
|---|---|---|
| `monitor.node_interval_seconds` | 监控频率（秒） | `60`（最小 30） |
| `monitor.node_offline_timeout_seconds` | 心跳超时判定阈值（秒） | `120` |

- **离线告警**：节点从在线变为离线时，发送 admin 模板「**节点离线告警**」，变量 `{node}`（节点名）、`{time}`
- **恢复通知**：节点从离线恢复在线时，发送 admin 模板「**节点恢复通知**」，变量同上
- **静默跳过**：状态未变化的轮次不发任何消息；面板重启后首轮只建立基线，不误报
- **只监控不发**：把对应模板停用（Enabled=OFF）即可

## 七、节点月流量配额告警（自动）

- **触发**：节点月流量达到配额阈值时发「**节点流量配额告警**」；超过 100% 触发挂起时再发一条超限告警（事件键 `traffic_quota_threshold` / `traffic_quota_exceeded`）
- **阈值**：设置键 `monitor.traffic_quota_threshold_percent`（百分比，默认 `80`，设 `0` 关闭阈值告警）
- **去重**：每账期每节点最多一条（账期按节点的流量重置日 `traffic_quota_reset_day` 计算）
- 可用变量：`{node}`（节点名）、`{used}`（已用 GB）、`{quota}`（配额 GB）、`{percent}`（百分比）、`{time}`

## 八、备份结果通知（自动）

- **触发**：定时备份（BackupScheduler）执行后即时发送——成功发 admin 模板「**每日备份报告**」，失败（创建备份/读取存储/上传远端）发「**备份失败告警**」
- 可用变量：`{backup_file}`（备份名）、`{size}`（大小，仅成功报告）、`{message}`（失败原因，仅失败告警）、`{time}`
- **只监控不发**：模板停用（Enabled=OFF）时静默跳过

## 九、证书到期提醒（自动）

- **触发**：每日 09:05 扫描 7 天内到期的 `active` 证书，逐张发 admin 模板「**证书到期提醒**」
- **去重**：同一证书每天最多提醒一次；续期后到期日推出 7 天窗口即自动停止
- 可用变量：`{domain}`（证书域名）、`{expire_date}`（到期日期）、`{days}`（剩余天数）、`{time}`

## 十、核心进程异常告警（自动）

- **触发**：核心进程（xray/singbox）异常退出或代理进程（caddy/nginx）崩溃时**即时**发送 admin 模板「**核心进程异常告警**」，守护进程随后按指数退避自动重启
- 可用变量：`{core}`（进程类型）、`{restarts}` / `{max}`（重启次数/上限）、`{message}`（退出信息，仅核心进程）、`{time}`
- **只监控不发**：模板停用（Enabled=OFF）时静默跳过

## 十一、新用户注册通知（自动）

- **触发**：客户注册成功后**即时**发送 admin 模板「**新用户注册通知**」
- 可用变量：`{user}`（客户邮箱）、`{time}`

## 十二、使用方式

1. **添加模板**：通知设置 → 通知模板 → 添加模板 → 「从预设填充」选择预设后按需修改
2. **启用**：模板需勾选 Enabled 并保存；自动触发只处理启用的模板
3. **测试**：列表中点「发送」用示例变量实际发送一条（订阅者模板的演示邮件发到管理员发件人邮箱）
4. **即时通知**（业务代码）：调用 `NotifyClientEvent(ctx, db, settingSvc, eventKey, clientEmail, vars)` 可在事件发生点（充值、扣费、续费）即时发给单个客户，不受每日扫描限制
